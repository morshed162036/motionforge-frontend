# MotionForge Frontend Starter

A clean-room, original Astro + GSAP frontend starter inspired by motion-heavy product/creative websites.

## Stack
- Astro
- GSAP + ScrollTrigger
- Custom CSS
- Vanilla JavaScript

## Run
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```

## Implemented in this starter
- Fixed responsive navigation
- GSAP hero entrance timeline
- Infinite marquee
- Hover tilt feature cards
- ScrollTrigger reveal system
- Pinned horizontal-scroll showcase on desktop
- Sticky card stack
- FAQ + responsive footer
- `prefers-reduced-motion` fallback
